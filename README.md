# Deckhand

Deckhand is a free Android card games app that never goes online: Solitaire, FreeCell, Spider and TriPeaks, plus Texas Hold'em, Brag, Hearts, Whist, Rummy, Gin Rummy, Crazy Eights, Pontoon, Blackjack and Snap against named computer players, or with friends on up to four phones. No adverts, no account.
